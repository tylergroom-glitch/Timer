Help

    

      


        
Getting the hardware connected

        
Plug the DSAN dongle into USB, and run the Cat-5 from the Limitimer or
        PerfectCue into it. Then press Connect in the top bar.

        
The newer VC-2000-2 appears as two ports, one for the timer and one for cues,
        so press Connect a second time to pick up the other. The app works out which is which on its own by
        listening for a few seconds. After the first time it reconnects by itself on every launch.


        
Reading the top bar

        
The three dots are Cues, Timer and
        Link. Grey means nothing is arriving, green means data is flowing. Link refers to the
        remote viewer, not the hardware.


        
Putting a clock on a monitor

        
Press Show view, choose what to display, and pick a monitor.
        You can show the speaker timer, the cue arrows, or both side by side or stacked.
        F toggles full screen and Escape leaves it.


        
Sending a view to someone else

        
Open the Remote link window, tick what the viewer should see,
        and press Copy link. Anyone with that link sees the same clock and arrows on a phone or
        laptop. New link makes a fresh address and retires the old one. A passcode can be set so
        the link only opens for someone who has it.


        
Arranging the screen

        
Drag any window by its title bar or its body, and resize from the bottom-right
        corner. Windows shows and hides panels. Save an arrangement under a name with
        Save as… and switch between them from the Layout box. Lock freezes
        everything so nothing moves by accident once a show is running.


        
During a show

        
The timer mirrors whatever the Limitimer is doing, including the warning and
        red times set on the unit itself. Run of show tracks your segments and shows whether
        you are ahead or behind. Message puts a line of text on the speaker's screen — the
        preset buttons are one tap, or type your own.


        
When something is wrong

        
No arrows or no clock: open Dongles. It shows
        each connected device, whether data is arriving, and lets you force which is the timer and which is the
        cue system if it guessed wrong.

        
"Port is busy": another program has the dongle. Close any
        browser tab or second copy of this app that might be using it; the console retries by itself every few
        seconds.

        
Nothing at all: unplug the dongle, wait five seconds and plug
        it back in, leaving this panel open. It reconnects on its own.


        
Updates

        
The app updates itself whenever it has internet, and asks before installing so
        it never interrupts a show. With no internet it runs happily on the version it already has.
        Ctrl+Shift+B goes back to the version built into the app if an update ever misbehaves.
